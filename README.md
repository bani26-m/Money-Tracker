--------------MONEY TRACKER-------------
About the project 
Money tracker is a simple Python project designed to help users keep track of their money and expenses.
The project provides separate options for students and professionals.
*Features
Student Money Tracker
.Add money 
.Track food expenses 
.Track travel expenses
.Track shopping expenses 
.track other expenses 
.show current balance

How to  run
1. Open the project folder in VS code.
2.Make sure all python files are in the same folder.
3.open main.py.
4.run main.py.
5.select student or professional.
6.enter the required money and expense information.


PURPOSES
The purposes of this project is to create a simple money manangement program while learning Python programming and basic project structure.
